# Parent Needs Help

**Series:** When Your Parents Need You
**Book 1:** *Your Parent Needs Help—Now What? The First 30 Days After Everything Changes*
**Status:** New write. Blueprint v1.0 in place; chapter outlines pending.

## Layout

| Folder | What's in it |
|---|---|
| `editorial/` | Book blueprint, series writing rules, source-verification log, editorial report. Internal only. |
| `manuscript/chapters/` | The new chapters, written fresh. Reader-facing text only. |
| `manuscript/front-matter/`, `manuscript/back-matter/` | Author's note, how-to-use, disclosures; resources, source notes, appendix. |
| `research/` | Research notes and sources. The carried-over source list is unverified. |
| `reference/book-1-previous-draft/` | Everything from the earlier Book 1 draft (from the `Book1` repo), unchanged, for reference only. |

## Working rules

- All drafting in Markdown.
- Follow `editorial/series-writing-rules.md`.
- Every factual claim gets a row in `editorial/source-verification-log.md`.
- Unresolved factual or professional-review concerns go in `editorial/editorial-report.md`, never in the manuscript.
